# 🧮 Python Advanced Calculator

A feature-rich, beginner-friendly Python calculator built using core Python programming concepts. This project upgrades a traditional calculator with multiple mathematical operations, calculation history, input validation, and error handling.

## 🚀 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 📊 Quotient & Remainder
- √ Square Root
- ⚡ Power / Exponent
- 📈 Percentage Calculator
- 🧮 Factorial
- 🔢 Absolute Value
- 📝 Calculation History
- 🗑️ Clear History
- 🛡️ Input Validation
- ⚠️ Division-by-Zero Protection
- 🔄 Continuous Calculations
- 🚪 Proper Exit Option
- 🔢 Decimal Number Support

## 🛠️ Technologies Used

- Python 3
- Python `math` module
- Functions
- Conditional Statements
- Loops
- Lists
- Exception Handling
- User Input & Validation
