## ▶️ How to Run

### 1️⃣ Install Python

Make sure **Python 3.x** is installed on your system.

Check your Python version:

```bash
python --version
```

or:

```bash
python3 --version
```

### 2️⃣ Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/PYTHON_FUN_PROGRAMS.git
```

### 3️⃣ Enter the Directory

```bash
cd PYTHON_FUN_PROGRAMS
```

### 4️⃣ Run a Program

```bash
python filename.py
```

Example:

```bash
python calculator.py
```
